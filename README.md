# doomesp32s3lcd19
A 3D raycasting DOOM-like game built specifically for the **Waveshare ESP32-S3 1.9" LCD** (Non-Touch).

---------------------------------------

A personal project of making a doom-like game for my ESP32 S3 1.9 LCD by Waveshare. 
Controls:
- Look around: Tilt the board left or right.
- Walk: Tilt the board forward or backward.
- Shoot: Press the **BOOT** button on the board

Features a live HUD with health, ammo, kills, and a mini-map radar (still a bit of a work in progress like the entire project...)
